# CodeMemory
Organizational memory of WHY workarounds exist.

CodeMemory is beyond a simple code annotator. It provides an organizational memory of why workarounds exist, including:
- IDE hover cards
- PR comments
- Org-level debt ledger
- Root-cause clustering
- Privacy gate (on-prem/local-only mode)

## Limitations
- False negatives in candidate discovery.
- Best-effort privacy detection.
- Free-tier LLM limits.
