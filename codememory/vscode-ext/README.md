# CodeMemory VS Code Extension

This is a minimal extension that displays a hover card when you hover over code containing an anchor snippet of a tracked CodeMemory hack.

## How to Run

1. Open this `vscode-ext` folder in VS Code.
2. In your VS Code settings, set the `codememory.resultsPath` configuration to the absolute path of your `results.json` file.
   - Example: `C:\Users\Lenovo\Desktop\CodeMemory\codememory\data\results.json`
3. Press **F5** to start debugging.
4. A new "Extension Development Host" VS Code window will open.
5. In the new window, open any Python file from your project and hover over the code of a tracked hack to see the hover card!
