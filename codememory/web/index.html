Terms of Use

This is a demonstration project built for HackwithHyderabad 3.0. It is not a production service.

The sample repository, commit history, and all pull request data shown in this demo are synthetic. They were authored specifically for this demonstration and do not represent real code or real engineering incidents.

No accounts are required. No user data is collected. No authentication is performed.

The source code is provided as-is for evaluation purposes.

Privacy

CodeMemory does not collect, store, or transmit any personal data.

No cookies are set. No analytics scripts are loaded. No network requests are made beyond loading the static page assets and the local results.json data file.

All processing shown in the demo was performed offline during the build step. The web interface reads pre-computed results from a local JSON file only.
